Étape 3 : Héberger sur GitHub Pages (Méthode Web Simple)
Connectez-vous sur GitHub.

Cliquez sur le bouton + (en haut à droite) puis sur New repository.

Renseignez :

Repository name : portfolio (ou mezui2023.github.io).

Cochez Public.

Cochez Add a README file.

Cliquez sur Create repository.

Dans votre nouveau dépôt, cliquez sur Add file > Upload files.

Glissez-déposez vos deux fichiers (index.html et style.css).

Cliquez sur Commit changes.

Étape 4 : Activer la mise en ligne (GitHub Pages)
Dans votre dépôt GitHub, allez dans l'onglet Settings (Paramètres).

Dans le menu de gauche, cliquez sur Pages.

Dans la section Build and deployment :

Source : Deploy from a branch.

Branch : choisissez main (ou master) et conservez / (root).

Cliquez sur Save.

Attendez 1 à 2 minutes. GitHub affichera un message avec l'adresse web finale de votre portfolio, sous la forme :
